# 上下文路由（地图的地图）

会话起点先读本文件，再按需加载。规则层常驻，其余索引化、按需检索，代码解说默认冷存储。

## 加载铁律
- L1 宪法长驻：每次会话加载 `开发宪法.md`。
- L2 本路由常查：定位文件时读，不含正文。
- L3 代码解说默认不加载：仅任务明确涉及某模块时读对应单文件，禁批量读。

| 不确定 | 回本路由；仍不确定只读宪法+路由，问用户 |

## 污染防护
- P1 读源码优先读代码解说（已提炼），禁读原始大 `.java`。
- P2 代码解说默认不加载（铁律 L3）；批量读=反模式。
- P3 任务完成释放非长驻文档，不保留过时副本。
- P4 演化日志为唯一真相源；宪法版本唯一，改了 sync 长驻上下文即可。
