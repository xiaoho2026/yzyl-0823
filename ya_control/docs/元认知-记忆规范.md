# 元认知 · LLM 记忆筛选规范

约束 LLM 自身记忆行为（非代码改动，代码改动走开发宪法）。定位：长驻，与宪法同层。

## 固有约束
- K1 概率性：同指令可给不同解法，岔路天然多。
- K2 上下文有限：记错比记少更危险（污染系统性误导）。
- K3 无因果记忆：只记得"什么被采纳"，记忆须自解释强信号。
- 推论：记忆追求信号密度，不追求复盘完整。

## 波普尔记忆分层
筛选标准=可泛化性+可证伪性。
| 类型 | 记? | 证伪方式 |
|---|---|---|
| 一次性错误(特定触发) | ❌ | 不可泛化，记即污染 |
| 正确路径/SOP | ✅ | 下次复用，遇反例修订 |
| 系统级约束(宪法类) | ✅强记 | 违反即证伪，优先级最高 |
| 反模式(踩坑抽象) | ✅(只记抽象不记个案) | 再犯即触发，修订措辞 |
- 反例：❌`2026-08-23 那次.git损坏的5步` → ✅`NAS双向实时同步Git会导致.git损坏—禁`

## 三过滤器（写入长期记忆前必过）
- F1 泛化：`去掉项目名还成立?` 成立→通用SOP/宪法补篇；绑死具体文件/点号→不进长期记忆，仅进项目级 docs。
- F2 可证伪：`什么情况它会错?` 说清边界→记并标边界；说不清→不记（防迷信）。
- F3 污染成本：高成本(宪法级)须显式验证后落地；低成本(某组件用法)可记，错了自然修正不Blocking。

## 三层记忆架构
| 层 | 载体 | 内容 | 生命周期 |
|---|---|---|---|
| 工作记忆 | 会话上下文(临时) | 岔路/试错/中间推理 | 会话结束即焚 |
| 程序性记忆 | `.codebuddy/memory/` | 泛化SOP+跨项目原则 | 长驻，定期精简 |
| 陈述性知识 | `docs/` 宪法/演化/地图 | 项目"暂未被证伪假说集"，带版本 | 随仓库，可被反例证伪 |

## 实操纪律
- S1 写入前自问：去掉项目名成立? 半年后适用? 说得出错的条件? 不过关不写。
- S2 错误只沉淀为反模式（抽象句"别在X做Y"），禁记个案。
- S3 宪法级约束标可证伪条件（"若__发生则作废"），保留被推翻通道。
- S4 定期精简：每月扫 memory，删已证伪/已并入SOP者。
- S5 会话内岔路不外溢：试错/被否方案留上下文即可，除非抽象出可泛化结论否则不写长驻文档。

## 黄金法则
记走通的桥（可泛化正确路径+反模式），不记踩过的坑（特定触发个案）。上下文=试错沙盒会话即清；memory=波普尔筛选的待证伪强假说集。

## 与文档体系关系
- 本规范=宪法补篇，专约束 LLM 记忆，不约束代码改动（代码改动走宪法4~7章）。
- 与演化日志(代码怎么变=事实)、工作日志(B清单标记)互补：本规范=什么值得 LLM 长期记(筛选)。
- 本规范自身有反例→按波普尔精神修订本章，并在工作日志记录。
