# 演化日志（Evolution Log · 文档即代码的变更史）

> **本文件是"文档即代码"的执行证据**（见 `docs/开发宪法.md` 第 5B 章）。
> 每次**改代码**（含改 Node-RED 流、前端、conf.ini、配置）都必须在此写一条演化记录，
> 让 LLM（主要）和未来的自己知道：**改了什么、为什么、怎么发生的、如何回退、验证结果**。
> 不写演化记录的代码改动 = 视为未完成、禁止上线。
>
> **规则**：
> - 按时间**倒序**（新在最上），每条带唯一编号 `E-xx`。
> - 初始基线 `E-00` 固化"读懂时系统原貌"，是所有后续演化的对照锚点。
> - 任何改动同步更新 `代码解说/`、`系统解剖手册`、`设备点号速查表`、`工作日志`，并在本条"关联文档"注明。

## 演化纪律提醒（每次改动前默念）
1. 这是现场 bug 还是潜在隐患？→ 潜在只标 B 清单，不修（宪法 4.1）
2. 动的是不是硬协议边界？→ 是则禁止单独改（宪法 4.4）
3. 改完能单独回退吗？→ 不能则禁止（宪法 4.3）
4. 能在真机验证吗？→ 不能则转标记（宪法 4.8）
5. 改了代码，三件套文档 + 本演化日志同步了吗？→ 没同步 = 改动未完成（宪法 5B.2）
